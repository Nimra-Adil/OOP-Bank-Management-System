# OOP Bank Management System

A C++ banking management system developed using Object-Oriented Programming (OOP) concepts.

## Features
- Account management
- Current and savings accounts
- User login functionality
- Transaction management
- File handling

## Technologies Used
- C++
- Object-Oriented Programming
- File Handling

## Project Structure
- `projectmain.cpp` — Main program
- `Account.h` — Account class
- `Bank.h` — Bank management
- `CurrentAccount.h` — Current account operations
- `SavingsAccount.h` — Savings account operations
- `Transaction.h` — Transaction management
- `FileManager.h` — File handling
- `Login.h` — Login functionality

## How to Run
Compile `projectmain.cpp` using a C++ compiler and run the generated executable.
